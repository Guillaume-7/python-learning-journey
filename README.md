# Python Learning — 8-Week Plan

**Period:** 9 November 2026 – 3 January 2027
**Target workload:** Approximately 7–10 hours per week.

## How to use this folder

For each week:

1. Read `README.md`.
2. Watch the listed lectures or tutorials.
3. Complete exercises in `exercises/`.
4. Write pseudocode before implementing the project.
5. Put your Python code in `project/`.
6. Add tests in `tests/` and record results in `review/`.
7. Keep questions and explanations in `notes/`.

Try each task independently before looking for a complete solution. Ask for hints progressively.

## Suggested weekly time allocation

- University lectures/tutorials: 2 hours
- Guided coding exercises: 2 hours
- Independent challenge: 2–3 hours
- Mathematics and algorithms: 1 hour
- Debugging and review: 1 hour

C++ is intentionally not included in this eight-week plan. Focus on Python foundations first.

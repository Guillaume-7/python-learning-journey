# Week 8 — Independent Mini-Application

## Learning resources
- Review the most difficult CS50P topics
- Review MIT material on abstraction, functions, and testing

## Concepts
- Project planning
- Decomposition
- Combining previous concepts
- Independent debugging

## Project
Design and build a small application of your own using functions, lists or dictionaries, file storage, input validation, and at least five automated tests.

## Mathematics / computer science theory
Apply averages, percentages, frequency analysis, or algorithmic reasoning where useful.

## Deliverables
- [ ] Project specification
- [ ] Pseudocode
- [ ] Working application
- [ ] At least five tests
- [ ] Short explanation of design decisions

## Suggested workflow
1. Watch/read the resources and take brief notes.
2. Attempt the exercises independently.
3. Write pseudocode before coding the project.
4. Implement and test your solution.
5. Record what you learned and what remains difficult.

## Weekly reflection
- What can I now explain without notes?
- What did I implement independently?
- What bug took the longest to solve?
- What should I review next week?
